# Project conventions

## Language

- **Conversation language: Spanish.** Always communicate with the user in Spanish: answers, questions, explanations, summaries, status updates, and any interactive prompts. The user is not fluent in English, so responding in English causes friction.
- **Code language: English.** All source code identifiers (variable names, function names, class names, file names, type names) and code comments must be written in English. This is the project convention and matches industry standards.

The only thing that switches between Spanish and English is the channel: chat messages → Spanish, code → English.
